# Geo-Tagged Environmental Complaint & Reporting Portal

## Project Overview

The Geo-Tagged Environmental Complaint & Reporting Portal is a web-based system designed to make environmental pollution reporting easier, faster and more accurate.

The system allows users to report environmental problems such as illegal dumping, water pollution, air pollution, excessive waste and noise pollution.

Users can provide the location of the pollution using geo-tagging, upload photographic evidence and describe the issue.

The system helps organize complaints so that environmental issues can be identified, prioritized and addressed more efficiently.

## Problem Addressed

Environmental pollution is often noticed by citizens, but reporting it can be difficult.

Common problems include:

- Difficulty identifying where to report an issue
- Inaccurate or unclear pollution locations
- Lack of photographic evidence
- No simple way to track complaints
- Serious complaints may not receive priority
- Lack of centralized pollution information

The portal provides a centralized digital platform for submitting and tracking environmental complaints.

## Main Features

- Report Pollution
- Geo-Tagged Location
- Pollution Category Selection
- Photographic Evidence Upload
- Severity Selection
- Unique Complaint ID
- Complaint Tracking
- Pollution Information

## Reporting Process

1. Select the type of pollution
2. Enter the complaint details
3. Provide the location using geo-tagging
4. Upload photographic evidence
5. Select the severity
6. Submit the complaint
7. Track the complaint using its unique ID

## Technology Used

- HTML
- CSS
- JavaScript

## Geo-Tagging

The portal uses location information to identify where the pollution has occurred.

Geo-tagging helps provide a more accurate location for each complaint and can help authorities identify pollution hotspots and respond to issues more effectively.

## Severity Classification

Complaints can be classified based on their severity:

- Low
- Medium
- High
- Critical

This helps prioritize complaints that require faster attention.

## Expected Benefits

- Easier pollution reporting
- More accurate complaint locations
- Better documentation using photographs
- Faster identification of serious issues
- Improved complaint tracking
- Identification of pollution hotspots
- Increased citizen participation
- Reduced dependence on paper-based reporting
