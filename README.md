Pollution Reporting Website
About the Project

The Pollution Reporting Website is an AAM project developed to provide a platform for users to report pollution-related issues. The website allows users to submit information about pollution and helps organize the reported issues.

Project Features

Pollution issue reporting

User-friendly website interface

Collection of pollution-related information

Easy access to submitted reports

Responsive web design
